# Kurobe Gorge landscape assets

- `trees.webp` — Eight photographic-style tree cutouts created with the built-in Image Gen tool. Prompt specified a two-by-two transparent atlas of a Japanese beech, autumn maple, cedar and riparian alder in diffuse October daylight. A second prompt requested deep-green hornbeam, zelkova, oak and fir in the same lighting. The WebP preserves the generated alpha.
- `shingle.webp` — Generated orthographic texture of pale mountain-stream gravel, grey slate, quartz and damp sand under diffuse daylight. Built-in Image Gen; resized for WebGL.
- `mossy-schist.webp` — Generated four-metre gorge rock face with damp schist, fern fronds, tree roots and moss under diffuse daylight. Built-in Image Gen.
- The bedrock uses the existing [CC0 Rock Boulder Dry texture](../../afterlight/CREDITS.md). The forest floor reuses the [SUMMERTIDE tree canopy](../../summertide/CREDITS.md). The water uses the project's [Three.js water normal](../../shared/CREDITS.md) and a modified Three.js Water reflection shader.
- `slope-leaves.webp` is a cropped foliage sample from the supplied reference. The terrain blends it into exposed banks using world-space coordinates.
- Terrain, riverbed, forest distribution, cobbles and the surface shaders were authored for this real-time scene.
