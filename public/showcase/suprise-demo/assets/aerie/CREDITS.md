# AERIE / 雲上城

- Art direction: the fantasy sky-city reference image supplied by the user, interpreted as an original browser-explorable environment. No characters are included.
- `limestone.jpg`: generated with the built-in Image Gen tool. Prompt: neutral orthographic scan of worn ivory limestone ashlar, fine pores, staggered stone courses, diffuse light, thin mortar joints, tileable, no objects or text. JPEG runtime derivative.
- `sky.jpg`: generated with the built-in Image Gen tool. Prompt: photographic 360-degree equirectangular blue afternoon sky over a dense white cloud ocean, delicate cirrus, warm side illumination, no buildings, landscape or aircraft. JPEG runtime derivative. Used only for the distant atmosphere; architecture and nearby moving cloud billows are spatial geometry.
- `leaf.png`: generated with the built-in Image Gen tool. Prompt: single orthographic dark green laurel leaf with detailed veins, diffuse light, transparent background. 512 px RGBA runtime derivative, used on bent, instanced leaves.
- `preview.png`: actual WebGL scene capture using the scene's photo control, not the generated concept.
- Shared concrete normal and HDR illumination: see [shared credits](../shared/CREDITS.md).
- Architecture, columns, bridges, balustrades, domes, staircases, fountain, foliage placement and animated sailships are authored procedural Three.js geometry. All code and runtime art are stored in this project.
- `design/aerie/concept.png` is an Image Gen visual direction reference; it is not rendered as a scene background.
