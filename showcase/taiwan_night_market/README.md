# 逛夜市 / SAY YACHI｜第一人稱網頁漫遊

使用 **three.js + TypeScript + Vite**，將現有 v5 Blender 夜市場景轉成可以自由行走的網頁體驗。沿用六個街區、58 棟不同建築、116 個攤位及 20 台販賣機，加入台北市場實地錄音。

## 啟動

需要 Node.js 20.19+ 或 22.12+。

```bash
npm ci
npm run dev
```

開啟終端顯示的本機網址，點「開始逛夜市」。場景約 32.8 MB，初次載入需要等待。

```bash
npm test
npm run build
npm run preview
```

`dist/` 是可部署到靜態網站主機的完整輸出，使用相對路徑，包含場景、碰撞資料及音檔；直接以 `file://` 開啟 HTML 不受支援。音效不需要 Freesound 帳號、API key 或外站連線。此版本尚未部署到公開網址。

## 操作

| 功能 | 電腦 | 手機／平板 |
|---|---|---|
| 移動 | WASD 或方向鍵 | 左側虛擬搖桿 |
| 環顧 | 滑鼠；不支援鎖定時按住畫面拖曳 | 右側拖曳，可與左手同時操作 |
| 快走 | Shift | — |
| 暫停 | Esc 或右上角暫停 | 右上角暫停 |
| 續玩／重置 | 暫停選單 | 暫停選單 |
| 音量、靜音、畫質 | 選單；設定保存在本機 | 選單；設定保存在本機 |

右上角可切換繁體中文／English，語言會記住；`?lang=zh` 可直達中文版，`?lang=en` 可直達英文版。英文版包含選單、操作、街區名稱、錯誤提示與音效授權；場景中的台灣店家招牌保留原有文字。

右下角小地圖顯示位置與朝向，左上角顯示目前街區。視窗失焦、切換分頁或暫停時會停止移動並暫停音訊。音效由使用者按下開始後啟用。

## 場景與實作

- 直接使用 [v5 GLB](public/models/night-market.glb)，原始 Blender 場景未更動。原始資產紀錄見 [v5 場景說明](docs/night-market-v5.md)。
- 保留低多邊形幾何、中文招牌與像素貼圖；使用 Lambert 即時光照、半球光、月光與全區固定燈光。載入時將全部 239 個局部光源計算成頂點光照與道路光照貼圖，進入遊戲前就全部亮起；不依玩家距離開關，也不在每一幀運算 239 盞燈。
- 7,741 個由 Blender 物件範圍匯出的碰撞框，以空間索引加速檢查。玩家為半徑 0.24 m 的平面圓形，視點高 1.75 m；移動採小步進防穿透及沿障礙物滑行。
- 以物件碰撞框處理路邊障礙物，並非完整三角網格物理引擎。此版供平面街道漫遊，不含跳躍、樓梯爬升、實際交易或戰鬥。
- 畫面自動限制像素比，低幀率時降低解析度；可選省電／清晰。暫停時降低繪製頻率。低階手機仍可能需要省電模式。

### 專案結構

| 路徑 | 用途 |
|---|---|
| `src/main.ts` | 場景載入、燈光、移動／視角、狀態與小地圖 |
| `src/i18n.ts` | 中英文文案、語言切換及網址語系 |
| `src/static-lighting.ts` | 全區固定光照與道路光照貼圖 |
| `src/collision.mjs` | 空間索引、圓形碰撞與滑行 |
| `src/audio.ts` | 真實錄音、淡入淡出、區域混音、暫停與音量 |
| `src/style.css` / `index.html` | 響應式介面與操作、授權視窗 |
| `public/models/` / `public/data/` | 網頁版 GLB 與配置／碰撞資料 |
| `public/audio/` | 已下載的免費環境音與署名 |
| `scripts/export_web_colliders.py` | 在 Blender/MCP 中重新匯出碰撞框 |
| `tests/collision.test.mjs` | 穿透、滑行、邊界及實際夜市路線檢查 |

如 Blender 場景更新，重新匯出 GLB、複製 layout/building JSON 並執行碰撞匯出腳本；再執行測試與視覺檢查，勿只更新 GLB。

## 本次驗證

- `npm run build`、TypeScript 檢查與 4 項碰撞測試通過。three.js 核心分包約 548 kB（gzip 約 138 kB），Vite 的 500 kB 提示仍會顯示。
- 先使用 Codex 內建瀏覽器檢查實際畫面、行走、碰撞、拖曳環顧、音效及授權視窗。因其不支援自動多點觸控，另以 Playwright Chromium 驗證正式 `dist/`。
- 電腦 1280×720：開始 → 前進約 5.9 m → 靠近攤位停在 Z≈−32.29 → 拖曳轉頭 → 暫停／續玩／回到入口，均通過。
- 手機模擬 390×844：搖桿移動、雙指同時轉頭、放開停止、暫停與重置通過；844×390 橫向介面無溢出。尚未在實體手機量測效能。
- 兩段 MP3 成功解碼，Web Audio 輸出量測非零；暫停後 AudioContext 為 suspended。重新整理後音量及畫質設定保留。
- 正式版瀏覽器流程未記錄到 JavaScript 錯誤。自動化瀏覽器未授予 Pointer Lock，因此實測包含拖曳替代操作；標準 Pointer Lock 仍需在允許鎖定的實際瀏覽器確認。
- 已對照概念與實際桌面／手機截圖，檢查文字、版面、字級、配色、場景與控制位置；差異紀錄在[設計規格](docs/web/design.md)。


### 人物與人群（第二版）

- **32 種路人造型**：原有 2 種，加上 30 種新人物。含大人、長輩、青少年、孩童，不同髮型、臉型、眼鏡、帽子、身形及日常服裝。
- **12 種工作人員造型**：原有 2 種，加上 10 種新人物。含圍裙、廚師、飲料店、便利商店、服飾與花店等穿著。
- **102 位路人**：原本 2 位再增加 100 位；六個區域各隨機配置 17 位，避開入口與障礙物，32 種造型全部使用。
- **154 位工作人員**：116 個攤販各 1 位；36 間商店、2 處公共服務據點各 1 位。一般住宅、透天、封閉老宅未視為店家。配置清單包含每人的工作場所 ID、位置、朝向與活動範圍。
- 五種走路循環：一般、悠閒、輕快、孩童、長輩。以腳掌軌跡計算大腿與膝蓋角度，加入抬腳、腳掌翻轉、髖部起伏、擺臂，動畫速度依人物移動速度及身高同步調整。另外保留站立、招呼、看商品。
- 路人保留慢走、選攤位、停看 4–10 秒再離開；人群使用空間分格與攤位目的地預約，受阻時避讓或另選路線。每次最多處理 2 次選路，避免同時集中計算。
- 工作人員在所屬攤位後方、店內或公共服務入口招呼、偶爾挪步，距離工作錨點不超過 0.24 m。每個位置都經過現有場景碰撞幾何檢查。
- 256 人都持續以 20 Hz 模擬行為。近處骨架每幀更新，遠處改為 15／6 Hz；可見人物不會因距離而突然消失。每種造型共享模型、單一頂點色材質及動畫資料，每人有獨立骨架，接地陰影使用 instancing。
- 人物碰撞半徑 0.42 m；玩家 0.24 m。仍為平面身體碰撞，手指、揮手等末端不做逐骨骼物理模擬。購物是情境動畫，沒有實際交易或車輛。

資產與程式：

- `assets/characters-v2/night_market_crowd.blend`：44 人可編輯 Blender 原始檔；初版保留於 `assets/characters-v1/`。
- `scripts/crowd-designs.json`：逐人設計規格；`scripts/build_crowd.py`：透過 Blender MCP 執行的建模與動畫腳本。
- `assets/characters-v2/manifest.json`：三角形數、骨架、動畫、來源及 GLB SHA-256；`public/models/crowd/`：44 個獨立 GLB。
- `public/data/crowd-catalog.json`：遊戲造型目錄；`public/data/staff-placements.json`：每個攤販及店家的人員配置。
- 調整場景後，執行 `node scripts/place_crowd_workers.mjs` 重新產生安全工作位置；找不到位置會報錯，不會默默漏掉店家。
- `window.nightMarket.characters` 提供唯讀人數、造型數、工作場所、行為、移動距離與停看次數。

驗證：`npm test` 包含完整 256 人、兩組各 15 分鐘的模擬，檢查人群／玩家／場景碰撞、工作範圍、全店覆蓋及每位路人的持續閒逛。瀏覽器畫面及性能記錄見 `docs/web/characters-v2-qa.md`。
