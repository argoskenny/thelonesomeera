# 迷你奇境 Mini Fantasy

一款以 Three.js 製作的可愛低多邊形 3D 小型 RPG。玩家從微風村出發，和 NPC 對話、收集月光莓、開啟寶箱、擊退森林魔物，最後挑戰苔角守衛。

## 啟動

```bash
npm install
npm run dev
```

正式驗證：

```bash
npm test
npm run build
npm run preview
```

## 操作

- `W A S D`／方向鍵：移動
- `E`：對話、採集、開寶箱
- `空白鍵`：揮劍攻擊
- `Q`：使用莓果藥水
- 手機／觸控裝置：使用畫面左右兩側的虛擬搖桿與動作按鈕

## 完整流程

1. 和村屋前的米菈交談並接受任務。
2. 穿過風鈴石橋，在月影森林收集 3 顆月光莓。
3. 回村把月光莓交給米菈，取得葉語護符。
4. 前往古樹谷地，擊敗苔角守衛。

皮平可以免費恢復生命；村莊與森林各有一個寶箱，會提供金幣、藥水與少量治療。

## 技術

- Vite + TypeScript + Three.js
- 全部角色、建築、樹木、道具與特效皆為程序化低多邊形 3D 幾何，不依賴外部模型
- 鍵盤與觸控操作
- 純函式冒險狀態與 Vitest 流程測試
- 部署基底路徑：`/showcase/mini_fantasy/`
