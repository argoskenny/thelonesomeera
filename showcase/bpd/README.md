# Sigil Keep

A five-room top-down puzzle game built with static HTML, CSS, and JavaScript.

Open `index.html` from a local web server. Move with the arrow keys, WASD, swipe gestures, or the on-screen directional pad. Push every stone block onto a glowing sigil, collect the key when a room contains one, avoid spike traps, and enter the awakened door.

- `R` resets the current room.
- `Ctrl/Cmd + Z` undoes the last move.
- The in-room recall stone also resets its room.
